## 代表实践

### 01 · 无接触式呼吸心跳监测学生原型

**角色：** 学生项目负责人；与团队共同完成。

**方向：** 毫米波雷达、ESP32、MQTT、远程查看。

项目探索以毫米波雷达采集人体呼吸与心跳相关信号，经 ESP32 处理和 MQTT 传输，在查看界面呈现结果。我负责学生项目的组织，以及感知、通信和显示环节的联调记录。相关竞赛版本获得第十四届“北斗杯”陕西赛区（含山西）本科组二等奖，并以“无接触式测量呼吸心跳装置”获得中国大学生计算机设计大赛山西省级赛三等奖。

[查看项目说明与系统流程](projects/contactless-vitals.zh-CN.md) · [北斗杯证书](assets/awards/award-07.jpg) · [计算机设计大赛证书](assets/awards/award-14.jpg)

<sub>这是学生演示原型；现有材料不支持医疗用途或测量精度的承诺。竞赛装置与后续演示链路在项目说明中分别描述。</sub>
