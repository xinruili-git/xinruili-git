### Contactless vital-sign monitoring · A student prototype

I led a student prototype exploring contactless respiration and heart-rate monitoring. The device used a millimeter-wave radar for sensing, an ESP32 for processing and connectivity, MQTT for remote transmission, and a viewing interface for the output. My contribution centered on the project plan and the integration of sensing, communication, and display. This was a demonstration prototype; I do not present it as a medical device or claim a measured accuracy that the available records do not establish.

**Explore:** [Project notes and system flow](projects/contactless-vitals.md)
